Welcome

CMPE 789 introduces modern cloud computing systems and the principles behind their design and development. It meets in person twice a week during the Fall 2025 semester and is taught by Chongzhou Fang.

The course covers the fundamental concepts and technologies behind cloud systems: concurrency and parallelism, cloud networks, data storage systems, cloud hardware and software infrastructure, the major cloud delivery models, resource management and scheduling, virtualization, cloud security, and cloud application development and performance optimization. The second half of the semester turns to advanced topics — heterogeneous computing, modern resource scheduling, machine learning in cloud environments, cloud and IoT integration, cloud security research, and future cloud infrastructures. Students explore these concepts through a combination of lectures, hands-on assignments, and a semester project.

Course learning outcomes

Upon successful completion of this course, students will be able to:

  • Develop, optimize, and deploy cloud applications and services on public cloud platforms;
  • Understand cloud system design principles and apply cloud resource management and scheduling techniques to design and deploy small-scale cloud infrastructures;
  • Analyze and utilize heterogeneous computing resources, such as GPUs and accelerators, to improve cloud application performance;
  • Apply cloud application development and performance optimization techniques to build scalable and efficient cloud services;
  • Understand security challenges and protection mechanisms in cloud computing environments;
  • Gain knowledge in emerging topics and trends in cloud computing, including machine learning in cloud environments, cloud–IoT integration, and future cloud infrastructures.

Class structure

Two 75-minute lectures per week, Tuesday and Thursday. Lecture notes and reading materials are posted on MyCourses and GitHub before each class, and students are expected to review the assigned materials before attending — class time is spent on lectures and concept discussion. Active participation is expected throughout the semester.

Coursework runs in three parallel streams:

  • Homework (40%). HW 1–4 combine concept review questions with hands-on programming on public cloud platforms and cloud simulators. HW 5 is a 6-page literature review on an advanced topic of your choosing. The lowest score among HW 1–4 is dropped.
  • Quizzes (10%). In class every two weeks on Tuesdays, starting Week 3. Concept understanding questions plus simple calculation problems. Lowest score dropped.
  • Semester project (50%). Teams of at most two students, building either a research-oriented project on novel cloud technology or a cloud application incorporating at least two of the advanced topics covered in class. It proceeds through team formation, idea approval, a four-page proposal with an in-class presentation, a checkpoint report, and a final presentation with a 10-page report.

Submissions. Written work uses the USENIX LaTeX template and is submitted in PDF format. Code is best submitted through GitHub. Homework is due at 11:59 PM on the due date; late submissions are penalized 10% per day.
